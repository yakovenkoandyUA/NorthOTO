# Сайт Північного Київського територіального управління

Статичний сайт на Astro і два PHP-скрипти: вакансії з Google Таблиці та надсилання анкети листом.

## Розробка

```sh
npm install
npm run dev
```

Локально PHP не використовується: вакансії беруться з `src/data/vacancies.sample.json`, а надсилання форми імітується. Стани блоку вакансій можна перевірити через `/?state=empty` і `/?state=error`.

## Де що редагувати

| Що | Де |
|---|---|
| Слоган, частини, програми | `src/data/site.ts` |
| Емблеми й фото | `public/img/`, шляхи вказуються в `src/data/site.ts` |
| Фото на плитках при наведенні | поле `tilePhoto` частини, зараз там згенеровані заглушки з `public/img/units/`; бажано від 1000 px завширшки |
| Поля форми | `src/components/ApplicationForm.astro`, `public/api/lib.php`, `public/api/contact.php` |
| Пошта й соцмережі у футері | у `src/data/site.ts`: `contacts` для управління, поле `contacts` кожної частини для її сторінки |
| Політика конфіденційності | `src/pages/privacy/index.astro` |

## Таблиця вакансій

Шаблон колонок: `docs/vacancies-template.csv`. Обов'язкові колонки: `Опубліковано`, `Частина`, `Посада`; необов'язкова: `Опис`. Порядок колонок не важливий.

- `Частина` починається з номера в/ч (`3066` або `3066 — 27 Печерська бригада`), для підрозділів поки `pd-1` і `pd-2`.
- `Опубліковано`: прапорець або `TRUE`. Інші рядки на сайт не потрапляють.
- Рядки з однаковими `Посада` та `Опис` стають однією карткою з кількома частинами. Якщо опис відрізняється хоч трохи, це будуть дві окремі картки.
- Публікуйте лише цю вкладку: вона доступна всім, хто має посилання.

Секція вакансій тимчасово має два варіанти (`src/pages/index.astro`): картки з об'єднанням за посадою та окрема картка на кожен рядок таблиці. Після вибору приберіть зайвий варіант разом із `<details>`.

Зміни з'являються на сайті за кілька хвилин. Якщо таблицю зламати (наприклад, перейменувати колонку), сайт лишить останній робочий список.

## Викладення на хостинг

1. `npm run build`
2. Завантажити вміст `dist/` у кореневу теку сайту.
3. Обрати PHP 8 у панелі хостингу та увімкнути перенаправлення на HTTPS.
4. На сервері скопіювати `api/config.example.php` у `api/config.php` і заповнити. Цей файл не входить до збірки й не зникне, якщо нова збірка не видалятиме його.

Після першого викладення перевірте: `/api/vacancies.php` повертає JSON, тестова анкета доходить на пошту, а `/api/config.php` і `/api/.storage/` дають 403.

## Демо на GitHub Pages

Кожен пуш у `main` збирає демо-версію через `.github/workflows/deploy-demo.yml`. У налаштуваннях репозиторію треба один раз обрати Settings → Pages → Source: GitHub Actions.

Демо показує тестові вакансії, не надсилає анкети й закрите від пошукових систем (`noindex`), але доступне кожному, хто має посилання. PHP-файли до нього не входять.
